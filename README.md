# Machine Vision Projects

A collection of Machine Vision practicals and projects developed using Python and OpenCV.

## Projects Included

### 1. CCTV Image Enhancement
- Image preprocessing
- Noise reduction
- Contrast enhancement

### 2. Product Measurement System
- Object dimension measurement
- Contour detection
- Pixel-to-real-world conversion

### 3. Metal Defect Detection
- Crack detection
- Surface defect identification
- Morphological operations

### 4. Road Sign Recognition
- Traffic sign classification
- OpenCV image processing

### 5. Face and Eye Detection
- Haar Cascade based detection
- Real-time webcam processing

### 6. Emotion Recognition
- Happy
- Sad
- Neutral
- Surprise

### 7. Vehicle Detection using YOLOv3
- Real-time object detection
- Vehicle localization
- Bounding box visualization

## Technologies Used

- Python
- OpenCV
- NumPy
- Matplotlib
- YOLOv3
- DeepFace

## Installation

```bash
git clone https://github.com/varunpathak2005/Machine-Vision.git
cd Machine-Vision
pip install -r requirements.txt
```
